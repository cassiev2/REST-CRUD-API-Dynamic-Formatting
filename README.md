# REST-CRUD-API-Dynamic-Formatting

## What it is:
A tiny REST API for a book list. Demonstrates CRUD endpoints and an HTML page: table, error handling, and a loading spinner

## How to run:
1. Clone the repo
2. Install Flask in the project folder (assumes Python already installed):
   - open a terminal window, go to project directory
   - create a virtual environment, run: python -m venv venv
   - activate it, submit: venv\Scripts\activate
   - install Flask, submit: pip install Flask
3. Start the Flask server, submit: run python app.py. It runs at http://127.0.0.1:5000.

## Browser commands:
  - HTML table: http://127.0.0.1:5000/goodbooks/html
  - raw JSON: http://127.0.0.1:5000/goodbooks

## Other operations:
  - Use curl for the other operations (add, update, delete)
